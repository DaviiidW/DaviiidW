## 🚀 Proyectos destacados

### 🏠 [Rooma](https://github.com/ISPP-ROOMA/rooma-wpl)
Aplicación web para buscar y gestionar apartamentos, desarrollada en un equipo de 16 desarrolladores.
- Integración con Cloudinary para almacenamiento de imágenes en la nube.
- Lógica de backend del sistema de valoración de candidatos, matching propietario-inquilino y gestión de incidencias.
- `React` · `Vite` · `Spring Boot` · `PostgreSQL` · `Docker` · `Cloudinary`
- 🔗 [Demo](https://rooma-wpl.vercel.app/)

### 🕸️ [TechGraph](https://github.com/DaviiidW/CBD)
Aplicación web para explorar tecnologías y proyectos mediante un sistema de recomendación basado en grafos.
- Sistema de recomendación con Neo4j Graph Data Science (algoritmos de similitud y escritura de relaciones).
- Sistema tipo RAG que construye contexto estructurado desde Neo4j.
- Chatbot integrado con Gemini 3.5 Flash con historial de conversación y contexto de dominio.
- `Django` · `Neo4j` · `Neomodel` · `Gemini`

### 🌿 [Natursur](https://github.com/PGPI-G2-4-2025-26/Natursur-Herbalife)
E-commerce de productos de nutrición desarrollado como proyecto empresarial.
- Módulo de gestión de pedidos (creación, actualización y consulta).
- Pruebas unitarias y de integración con Django TestCase, RequestFactory y test client.
- `Django` · `SQLite` · `Playwright`

### 🏖️ [Bookiri](https://github.com/DaviiidW/bookiri)
Aplicación web para gestionar alquileres vacacionales, diseñada y desarrollada en solitario de principio a fin.
- Calendario de reservas con cálculo automático de precios por temporada.
- Sistema de enlaces públicos de solo lectura para compartir disponibilidad y precios sin autenticación.
- `Next.js` · `React` · `TypeScript`
- 🔗 [Demo](https://bookiri-coral.vercel.app/)
